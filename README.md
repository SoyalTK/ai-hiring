# 🚀 Job Hiring Assistant

AI-powered hiring assistant that analyzes resumes, matches them with job descriptions, and provides ATS-style feedback. It also includes a recruiter mode to compare up to 20 resumes and generate an AI leaderboard for quick candidate selection.

---

## ✨ Features

- 📄 Resume Analysis with AI feedback  
- 🎯 Job Description Matching & ATS Score  
- ✍️ Resume Improvement Suggestions  
- 🧑‍💼 Recruiter Mode (Compare up to 20 resumes)  
- 🏆 AI Leaderboard Ranking System  

---

## 🛠️ Tech Stack

- **Frontend:** React  
- **Backend:** Node.js, Express  
- **AI Integration:** Groq API  
- **File Handling:** PDF Parsing
